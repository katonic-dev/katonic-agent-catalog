## 1. How to read this matrix

1.1 Each dish has one row. The row lists every allergen the dish **contains** as a declared ingredient.

1.2 If a dish is not in this matrix, there is no allergen information for it. Do not work it out from the name of the dish, from a similar dish, or from an ingredient list. Ask the restaurant manager.

1.3 This matrix does **not** cover cross-contact in the kitchen. All dishes are prepared in a kitchen that handles gluten, milk, egg, soy, sesame, tree nuts and mustard. No dish can be described as free from any allergen.

1.4 This matrix does **not** cover a change to a dish (an added topping, a removed ingredient, a swapped sauce or a different base). A changed dish is a different dish. Ask the restaurant manager.

1.5 Nobody may tell a guest that a dish is suitable or safe for them. Read out the row. If the guest has an allergy, the restaurant manager speaks to the guest.

1.6 Limited-time dishes are added to the matrix before launch. A limited-time dish that is not in this version has no allergen information yet.
